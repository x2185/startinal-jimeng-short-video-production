# Final approval gate

Run this after automated prompt review and before each initial paid generation.

## Present for approval

- Chosen 30-second story: one-sentence plot plus the 0–10s, 10–20s, and 20–30s beats.
- The three final prompts, not drafts.
- Every attached reference asset and its role: fixed product identity; prior approved handoff frame when applicable.
- Verified claims that will appear, plus any disclosed assumptions.
- Any remaining material risk: scene/product mismatch, uncertain prop, continuity risk, or claim ambiguity.

## Approval rule

Ask a direct question such as: “Approve this package for JiMeng generation?” A paid request is authorized only after a clear affirmative response naming the package or unmistakably referring to the displayed package. Silence, a general desire to make videos, or approval of a previous version does not authorize submission.

When the reviewer identifies a mismatch, revise the story, prompts, or assets and show the changed package again. Do not submit the earlier version.

## After each generated clip

Use the reference-frame gate and show the selected handoff frame before submitting the continuation whenever the scene, product, or actor continuity is material. Ask for re-approval if the selected frame changes the intended story or has a visible risk.
