# Generative action-risk gate

Use this gate when a product video needs an action that changes the product's visible state.

## Choose the reliable layer

Use generated video for a product that is already complete: lifestyle story, dialogue, reaction, gifting, carry/use context, stable hero display, or a simple result beat. Keep the product as a clearly visible prop with one low-risk movement such as lifting, setting down, or a small orientation change.

Use the supplied real footage, or a deterministic edit of it, for an operation when its correctness depends on hidden geometry, exact alignment, a slot, a thread, a hinge, a seal, a connector, a card, a button sequence, a close mechanical contact, or a result that must be trusted. A source image that merely shows the product cannot prove every intermediate state.

## Test before spending

When the action is evidence-backed but potentially fragile, test the lowest-risk prerequisite first:

1. Lock the completed product identity with a static or small-motion test.
2. Test one state change only, with no dialogue, setting change, payment result, or secondary action.
3. Continue only if the product silhouette, parts, scale, hands, and ending state all pass.

Stop paid retries when the same action class changes product identity more than once. Revise the layer choice instead of lengthening the prompt: use real action footage and let generated scenes cover the surrounding story.

## Story-first default

For products whose main operation is high risk, create a story-first package:

- Start with a relatable situation or light reaction.
- Show the fully assembled product in a clear, stable close shot.
- Use a simple outcome or human reaction, not an inferred mechanism.
- If installation or payment proof is needed, insert an approved real-footage clip as a separate deterministic edit; do not ask one generated clip to explain the whole sequence.

Do not turn this gate into a universal ban on actions. Use simple, visually supported actions when the product identity remains clearly observable and the action has a stable, low-risk end state.
